AI product features

Answers grounded in your own data, actions the model never takes on its own, and a record of every turn.

Retrieval-augmented generation and agents that run in production, not in a notebook. I have built it twice: at Parallel with LangChain against OpenAI and Anthropic on pgvector and Pinecone, and in Saidic, which I founded, with hybrid retrieval over pgvector, full-text and exact matching, a small decision model for routing, every reply checked against its cited sources, and a trace of what each turn read and cost. When the model has to act, deterministic thresholds decide and the customer confirms, the credentials are encrypted, the outbound calls are guarded against reaching your internal network, and visitor text is never treated as an instruction.

You get

  • Ingestion from your sources into passages and embeddings, with the re-indexing that happens when the source changes
  • Vector search on pgvector where your data already lives in Postgres, or Pinecone where it does not, plus hybrid full-text
  • Tool calls against your systems with a human or customer approval step, encrypted credentials, and SSRF-safe outbound requests
  • A record per turn of what was retrieved, what was checked, how long it took and what it cost, plus an adversarial test suite before each release
  • The same deploy as everything else: a container, a pipeline, Terraform

A platform on AWS

Infrastructure you can read, and a pipeline that ships every service the same way, with no static cloud keys in it.

If your services are deployed by hand, or by a script only one person understands, I turn that into Terraform IaC and CI/CD. Every piece of AWS becomes code in a reviewed merge request: ECS Fargate services, EC2, Lambda, SQS, EventBridge, S3, load balancers, ECR, IAM. Every push runs the tests, builds the image and deploys it on short-lived OIDC credentials. I did exactly this at Parallel over three and a half years, from no pipeline to one that handled every service, with per-pull-request preview environments, Sentry and CloudWatch alarms, and a full handoff when I rolled off.

You get

  • Terraform IaC for the whole AWS footprint, with state you can trust and a plan you can read before it applies
  • GitLab CI/CD or GitHub Actions with OIDC deploy roles and least-privilege IAM: tests, Docker image builds and deployments for every service, from scratch if needed
  • Containers on ECS Fargate, Lambda with EventBridge and SQS for the event-driven and scheduled work, and the judgement about which is which
  • Sentry, CloudWatch alarms and PII masking, plus Bash and runbooks for the operational tasks, so nobody has to remember the incantation
  • Signed, checksummed release artefacts when you ship something people install
