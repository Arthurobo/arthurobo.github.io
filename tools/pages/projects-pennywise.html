Install

go install github.com/Arthurobo/pennywise/cmd/pennywise@latest
pennywise init
pennywise start
  • 1binary. No Postgres, no Redis, no Node
  • 1SQLite file, backed up and restored with two commands
  • 3service managers it installs itself into, none needing admin
  • 4LLM providers, with your own key

Pennywise is a single-tenant, self-hosted expense tracker in the spirit of Plex, Jellyfin or Home Assistant: one install, one user, one SQLite file. It runs on a laptop, a home server, a Raspberry Pi or a NAS. No accounts on anyone else's server and no subscription.

One command, one service

pennywise start does not just launch a server. It installs Pennywise as a real OS service so it starts at every reboot and restarts itself if it crashes: a launchd LaunchAgent on macOS, a systemd user unit on Linux, a Task Scheduler task on Windows. All user-scoped, so no sudo and no service-file editing. The same pattern later became the service layer in AgentFlow.

The data

Everything lives in one SQLite file under your home directory. pennywise backup copies it, pennywise restore brings it to a new machine, and sqlite3 opens it whenever you want to look. Pure-Go SQLite means there is no C toolchain in the build and the binary is genuinely one file.

The optional AI

Log expenses by texting a Telegram bot: "5000 fuel", "how much this month?", or a photo of a receipt. The model that reads them is yours: bring an API key for OpenAI, Anthropic, Google Gemini or xAI, and Pennywise calls that provider directly. It never proxies your traffic through anything I run, which is the only honest way to do "AI" in a local-first tool.
