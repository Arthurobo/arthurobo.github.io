Projects

Things I built. Saidic is the product I founded and run; the rest are open source or demos, most of them in Go, each one something you can install and run.

  • Saidiclive 2026–present An AI agent for customer support that only says what you have told it: answers from the business's own knowledge, actions against its APIs with the customer's consent, human takeover from a live dashboard. Founded, built and run by me. FastAPI · PostgreSQL + pgvector · Redis + arq · WebSockets · Next.js · OpenRouter · Cloudflare
  • AgentFlowlive 2026 A background daemon that runs Claude Code and OpenCode in real PTYs on your computer and lets you drive them from your phone's browser. Cloudflare tunnel by default, your own Tailscale if you prefer, per-device pairing instead of passwords. Go · Next.js · SQLite · systemd / launchd / Task Scheduler · GitHub Actions · cosign
  • Scoutdemo 2026 A Slack hiring agent built on Trigger.dev as a demo for its founder. The approval step is a tool with no execute function, so the run suspends at no cost until a human says yes. Approver allowlist, draft hash, an atomic send claim and a unique index so nobody is contacted twice, all enforced in Postgres and code, not the prompt. Development environment only. TypeScript · Trigger.dev · Postgres · Slack
  • Job Nomad2026 Hybrid job search: typo-tolerant full-text, embeddings in pgvector, reciprocal rank fusion and a cross-encoder rerank, with a ranking-quality gate in CI so a change cannot quietly make results worse. A Go API with an internal Python AI service and a versioned agent protocol over WebSocket; the rerank model runs locally on CPU with ONNX Runtime, quantised, after measuring which model fit the latency budget. Go (chi, sqlc) · Python · pgvector · ONNX Runtime · WebSocket
  • Pennywiselive 2026 Local-first expense tracking. One Go binary, one SQLite file you can copy, installs itself as an OS service. Optional Telegram bot that logs "5000 fuel" or a photo of a receipt with your own LLM key. Go · SQLite · Telegram · OpenAI / Anthropic / Gemini / xAI
  • Saidizearly 2026 A personal assistant that uses your own Mac for you, through the same Accessibility interface screen readers use. Anything someone else would see is ask-first, with the full text shown before it goes anywhere. Private while it is early. Go · macOS Accessibility
