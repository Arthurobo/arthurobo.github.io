Projects

Things I built on my own time. Most of them are in Go, and each one ships as something you can install and run, with the service file, the installer and the release pipeline that implies.

  • AgentFlowlive 2026 A background daemon that runs Claude Code and OpenCode in real PTYs on your computer and lets you drive them from your phone's browser. Cloudflare tunnel by default, your own Tailscale if you prefer, per-device pairing instead of passwords. Go · Next.js · SQLite · systemd / launchd / Task Scheduler · GitHub Actions · cosign
  • Saidicin development 2026 An AI-first customer engagement platform. A chat widget that answers from the business's own knowledge and carries out actions against its systems, a dashboard for the team, and a backend that replaced seven services with one. FastAPI · SQLAlchemy · PostgreSQL + pgvector · Redis · Nginx · Next.js · WebSockets
  • Pennywiselive 2026 Local-first expense tracking. One Go binary, one SQLite file you can copy, installs itself as an OS service. Optional Telegram bot that logs "5000 fuel" or a photo of a receipt with your own LLM key. Go · SQLite · Telegram · OpenAI / Anthropic / Gemini / xAI
  • Saidizearly 2026 A personal assistant that uses your own Mac for you, through the same Accessibility interface screen readers use. Anything someone else would see is ask-first, with the full text shown before it goes anywhere. Private while it is early. Go · macOS Accessibility
